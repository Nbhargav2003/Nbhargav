# N. Bhargav — Portfolio

Live site: https://nbhargav2003.github.io/Nbhargav/

A personal portfolio site built to showcase my background as a Software Engineer with a foundation in Internet of Things (IoT).

## About

Recent B.Tech graduate (IoT) from Presidency University, Bengaluru, focused on software engineering roles. This site covers my background, skills, and projects, and includes a downloadable resume and direct contact options.

## Built With

- HTML5, CSS3, and vanilla JavaScript (no frameworks, no build step)
- Fully responsive — works on desktop, tablet, and mobile
- Hosted with GitHub Pages

## Features

- Interactive "Hire Me" toggle that opens a contact panel with email, LinkedIn, GitHub, and resume links
- Downloadable, ATS-friendly resume (PDF)
- Animated skill gauges, project cards, and scroll-based reveals
- Mobile-friendly navigation with a sticky quick-contact bar
